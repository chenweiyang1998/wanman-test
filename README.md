# Wanman Test Project

A test project for the wanman multi-agent system.

## 项目目的

本项目旨在测试和演示 wanman 多代理协作系统的工作流程，包括：

- 任务分解与分配
- 多代理协作开发
- 代码审查与合并流程
- 文档同步与维护

## 项目结构

```
.
├── .editorconfig    # 编辑器配置
├── .gitignore       # Git 忽略规则
├── LICENSE          # MIT 许可证
├── README.md        # 项目说明文档
├── CHANGELOG.md     # 变更日志
├── CONTRIBUTING.md  # 贡献指南
└── docs/            # 文档目录
    ├── ARCHITECTURE.md  # 架构文档
    └── SUMMARY.md      # 文档概览
```

## 开发流程

1. **任务创建**: 通过 wanman 系统创建任务
2. **开发执行**: Dev agent 实现功能
3. **代码审查**: CTO agent 审查 PR
4. **合并部署**: 通过审查后合并到主分支
